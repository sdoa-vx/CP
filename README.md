## 🌌 What is SDOA?
**SDOA** stands for **Self-Describing Object Architecture**. It is a revolutionary, polyglot software design paradigm that enforces strict structural constraints, runtime analytics, and self-documenting boundary contracts (known as *Sleeves*) across an entire software ecosystem. 

SDOA transforms brittle, tightly-coupled codebases into an autonomous, self-healing grid of independent components governed by intelligent "Authorities" (such as the *Oracle*, *Cartographer*, and *Probation Officer*).

## 🚀 The Migration and Creation Engine (MCE)
This VS Code Extension serves as the official **Model Context Protocol (MCP)** companion for the SDOA framework. It is the bridge between your raw source code and the AI-driven SDOA mesh.

### Core Capabilities:
- **Scanner 2.0 (The Looking Glass Pipeline):** Scans your workspace to intelligently identify monolithic code that can be automatically extracted and refactored into modular SDOA *Sleeves*.
- **Proposal Generation:** Instead of just pointing out flaws, the engine actively generates complete, AI-authored structural proposals directly into your cloud registry (Supabase) to migrate legacy code into the SDOA paradigm.
- **Pulse Scoring & Mesh Telemetry:** Monitors the real-time "health" of your architecture, grading your modules on drift vectors, transport resilience, and batch execution efficiency.
- **Polyglot Awareness:** Seamlessly handles multi-language capability boundaries across Rust, Go, TypeScript, Python, and C++.

---

## 🛠️ Features

* **Real-Time SDOA Cognizance Panel**: Monitor active module drift, routing telemetry, and structural integrity straight from your IDE.
* **One-Click Scanning**: Use the command palette (`sdoa.scanWorkspace`) or the UI to scan your codebase and feed it to the AI Looking Glass pipeline.
* **Unified Dashboard**: Automatically launches the local `tracksdoa-v2` dashboard to visualize your project's historical topology (TimeMachine) and active mesh logs.

## ⚙️ Setup & Configuration

1. Install the extension.
2. Ensure the **Sovereign Mesh** cluster daemons are actively running in the background.
3. Open the command palette (`Ctrl+Shift+P` or `Cmd+Shift+P`) and type `SDOA: Scan Project for Innovations` to begin migrating your codebase into the future!
