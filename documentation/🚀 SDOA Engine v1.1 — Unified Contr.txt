🚀 SDOA Engine v1.1 — Unified Control Center Release
A fully interactive, real‑time architectural intelligence system for VS Code and the Web Dashboard.
This release transforms the SDOA Engine from a passive background daemon into a first‑class, developer‑facing control system with live telemetry, real‑time event streaming, workspace heatmaps, and one‑click architectural refactoring actions.

v1.1 is the first release where the SDOA Engine behaves like a true platform — observable, controllable, extensible, and deeply integrated into the developer workflow.

⭐ 1. VS Code Control Panel (New Activity Bar Integration)
A brand‑new SDOA Engine panel now appears in the VS Code Activity Bar, providing a native command surface for the entire platform.

New Features
Live Engine Status (Idle / Scanning / Syncing / Error)

Last Scan Timestamp

Queue Depth & Pending Sync Count

AST Cache Size

Detector Status Overview

Quick Actions:

Run Full Workspace Scan

Scan File

Scan Folder

Restart Engine

Open Local Dashboard

View GitHub Releases

View GitHub Pages Documentation

The Control Panel updates automatically every 1.5 seconds using a lightweight polling layer.

⭐ 2. Web Dashboard 2.0 — Real‑Time Control Center
The dashboard at http://localhost:8080/dashboard has been completely rebuilt into a multi‑panel, interactive monitoring console.

New Panels
Overview — Engine state, queue depth, AST cache, SQLite size

Detectors — Status, thresholds, last trigger, match counts

Telemetry — Charts for detector hits, cache growth, sync activity

Events — Live event stream with real‑time updates

Heatmap — Workspace duplication density visualization

Settings — Toggle detectors, adjust thresholds, enable/disable AI

New Header Actions
Scan File

Scan Folder

Restart Engine

Live Engine State Indicator

The dashboard now behaves like a local developer console, not a static page.

⭐ 3. Engine Telemetry Layer (New Subsystem)
A new internal telemetry module continuously tracks:

Engine State

Last Scan

Queue Depth

AST Cache Size

SQLite DB Size

Detector Hit Counts

Sync Status

Engine Uptime

All telemetry is exposed via:

Code
GET /dashboard/api/state
GET /dashboard/api/telemetry
This enables both the VS Code panel and the dashboard to stay in sync.

⭐ 4. Event Stream Protocol (SSE‑Powered Live Logs)
The SDOA Engine now emits structured events for:

AST cache warm

Detector triggers

Offline queue flush

Sync success/failure

Engine restart

Pipeline decisions

A new Server‑Sent Events endpoint streams updates in real time:

Code
GET /dashboard/api/events
The dashboard displays these events instantly in the Event Stream panel.

⭐ 5. Workspace Heatmap (New Visualization Layer)
A new backend route analyzes duplication density across the workspace:

Code
GET /dashboard/api/heatmap
The dashboard renders a color‑coded tree:

Red → High duplication

Yellow → Moderate

Green → Clean

This gives developers a visual map of architectural hotspots.

⭐ 6. Fix‑It Actions (One‑Click Architectural Refactoring)
Each detector now supports one‑click automated extraction:

UI Primitive Detector
→ Extract repeated JSX into ui/primitives/<name>.tsx

Workflow Detector
→ Extract repeated fetch/IPC patterns into server/workflows/<name>.ts

Schema Detector
→ Extract repeated interfaces/forms into ui/data/schemas/<name>.ts

Token Detector
→ Extract repeated CSS values into ui/tokens.css

Engine Detector
→ Extract repeated process execution signatures into substrate/engines/<name>.ts

Each Fix‑It Action opens a diff preview so the developer can approve or reject the change.
